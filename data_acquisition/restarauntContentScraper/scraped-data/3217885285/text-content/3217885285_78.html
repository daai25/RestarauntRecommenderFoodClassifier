Questions fréquentes

Où se trouvent le webmail, mes contacts et mes rendez-vous ?

Le nouveau webmail peut être consulté sur webmail.hoststar.ch. Veuillez vous y connecter avec votre adresse e-mail, au lieu d'utiliser votre numéro web comme jusqu'à présent.

Attention : les données de contact et de calendrier ne sont disponibles que dans l'ancien webmail ! Vous trouverez l'ancien webmail sous https://login-X.hoststar.ch/poplogin.
Important : remplacez X par le numéro de votre hébergement web. Vous trouverez ici des instructions détaillées sur la manière d'accéder à l'ancien webmail. Des informations générales sur l'e-mail et le webmail se trouvent ici.

Comment puis-je charger des données sur mon hébergement web ?

Le moyen le plus simple est le FTP : avec le protocole de transfert de fichiers (FTP), vous pouvez charger des données directement sur votre espace web par glisser-déposer. Vous trouverez ici des instructions détaillées sur le thème du FTP sous le point Accès FTP.

Comment puis-je créer une nouvelle adresse e-mail ?

Vous gérez toutes vos données - y compris l'e-mail - dans My Panel, connexion via my.hoststar.ch (instructions My Panel). Vous trouverez ici de plus amples informations sur le thème de la messagerie.
