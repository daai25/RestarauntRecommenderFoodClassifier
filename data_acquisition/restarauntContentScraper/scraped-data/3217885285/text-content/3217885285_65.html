Choisissez le nom de domaine souhaité

Les noms de domaine doivent comporter entre 3 et 63 caractères (hors extension). Veillez à saisir correctement le nom et assurez-vous que le domaine est libre ou se trouve déjà en votre possession.

Vous avez déjà un nom de domaine ?
Vous pouvez le saisir ici. Il servira de nom d'utilisateur pour la connexion à notre outil de gestion. Votre domaine peut également être transféré chez nous ultérieurement.

Chercher
Hoststar enregistre pour vous le domaine auprès des autorités compétentes et s’occupe de configurer le domaine dans son intégralité. La facturation s’effectue via Hoststar.
Vous enregistrez vous-même le domaine auprès de l’organisme d’enregistrement souhaité. Cet organisme d’enregistrement de noms de domaine vous adresse directement la facture pour l’enregistrement du domaine. Afin de pouvoir utiliser le domaine avec l’abonnement choisi, vous devez saisir nos serveurs de noms auprès de l’organisme ayant enregistré votre domaine. Vous recevez ces derniers après la commande.
