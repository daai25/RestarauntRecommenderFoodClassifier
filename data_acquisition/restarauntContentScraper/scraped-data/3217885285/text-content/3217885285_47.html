Questions fréquentes
autour de l'hébergement web

Nous répondons ici aux questions
les plus fréquemment posées sur l'hébergement.

Qu'est-ce que l'hébergement web ?

L'hébergement web consiste à stocker les données de sites web sur un serveur web ou sur l'espace de stockage du serveur.

Pourquoi un hébergement web ?

Un hébergement professionnel garantit un site web sécurisé, rapide et stable, ce qui est essentiel pour gérer des boutiques en ligne ou proposer des services en ligne.

Quel est le package d'hébergement web le plus adapté à mon projet web ?

Le choix du package d'hébergement dépend fortement de l'usage que vous souhaitez en faire. Le type de système que vous utilisez est également important. Notre plus petit pack StarEntry a déjà tout ce dont les débutants ont besoin. Pour les tâches plus complexes et les programmes qui nécessitent un accès externe à MySQL, StarBiz est parfait. Pour une performance maximale et un support premium, optez pour le paquet StarPlus.

Quelle est la différence entre SSD et NVMe ?

Les disques SSD (Solid State Drives) et NVMe (Non Volatile Memory Express) se distinguent par leur connexion au système et le protocole utilisé. Les disques durs SSD sont connectés au système via Serial-ATA III et utilisent le protocole AHCI. Les disques durs NVMe sont connectés au bus PCI Express, beaucoup plus rapide, et utilisent le nouveau protocole NVMe.

Que dois-je savoir si je veux utiliser mon espace web avec WordPress ?

Chez Hoststar, vous effectuez la connexion de votre espace web au CMS WordPress en un clic. Il vous suffit de connaître les fonctionnalités de WordPress, car dès que vous avez activé l'application, vous pouvez utiliser le CMS comme d'habitude.
