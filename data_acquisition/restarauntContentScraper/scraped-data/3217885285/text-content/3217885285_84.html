FTP web - SFTP

Accesso FTP

Grazie al File Transfer Protocol (FTP) potete copiare e scaricare in qualsiasi momento i vostri dati sul vostro hosting Web.

A tal fine vi consigliamo di usare Web FTP di Hoststar, il quale consente di trasferire i dati tramite browser, oppure di optare per un programma FTP gratuito presente nel nostro Download Center.

Per la codifica del collegamento FTP è disponibile il protocollo SFTP (SSH File Transfer Protocol). Con SFTP il collegamento FTP viene realizzato mediante un tunnel SSH, che consente di cifrare il trasferimento dei dati da e verso un server. Oltre ai comandi viene cifrato anche il canale dati; ciò significa che sono codificati sia i dati di accesso sia i dati normali. I nostri server sopportano di default il protocollo SFTP.

Caselle e-mail

Numero illimitato di caselle di posta elettronica

Gli account di posta elettronica offrono spazio di memoria per le vostre e-mail, e voi potrete creare un numero illimitato di account. Per ciascuna casella di posta elettronica può essere impostato un limite di memoria allocata (StarEntry: max. 5 GB, StarBiz: max. 15 GB, StarPlus: max. 20 GB).

In quanto clienti di Hoststar potrete utilizzare i seguenti protocolli di posta elettronica: POP3, IMAP4 e SMTP.
Il protocollo IMAP4 è stato progettato per consentire l’accesso alle caselle di posta elettronica e ai messaggi come se si trovassero sul computer locale. Al contrario di quanto accade nel caso di POP3, le e-mail rimangono sul server, dal quale vengono gestite. Il protocollo IMAP4 è la soluzione idonea se si desidera utilizzare lo stesso account e-mail su diversi dispositivi.

E-mail catch-all

E-mail catch-all

Con un indirizzo e-mail di tipo catch-all è possibile «intercettare» tutte le e-mail non classificabili. Vengono captate quindi tutte le e-mail inviate a «@vostrodominio.ch» che non possono però essere ascritte a un indirizzo e-mail (ad es. «info@vostrodominio.ch»).

Questa soluzione è pratica se ad esempio volete ricevere e-mail solo da «vostrodominio.ch». In questo caso non è necessario che creiate diversi account e-mail, ma potrete ricevere le e-mail su «info@vostrodominio.ch», su «rossi@vostrodominio.ch» o «contatto@vostrodominio.ch» sullo stesso account.

Filtro spam & scansione virus

Filtro antispam e scanner antivirus

  • La protezione antispam Hoststar è stata programmata sulla base dei valori empirici dei nostri competenti team di amministratori dei server e dell’assistenza e scansiona tutte le e-mail in arrivo.
  • La blacklist Hoststar inoltre è sincronizzata con tre database antispam internazionali. Ciò garantisce un blocco affidabile ed efficace dello spam. Registrando i server spam (Open-Relay-Server) nella blacklist, è possibile arrestare intere ondate di spam.
  • Il filtro antispam OCR di Hoststar (software di riconoscimento testuale per dati grafici) riconosce le e-mail di spam basate su grafici e le filtra in modo affidabile.

Quale misura di protezione contro e-mail e file infettati da virus, vi offriamo i seguenti scanner antivirus:

  • Lo scanner antivirus di Hoststar controlla tutte le e-mail e verifica che non vi siano contenuti infetti cancellando automaticamente le e-mail infette reperite.
  • In occasione di ogni upload e download sui nostri server la protezione antivirus FTP di Hoststar controlla tutti i file memorizzandoli solo dopo una verifica approfondita.

Protezione DDoS

Protezione DDoS

Con un attacco DDoS (Distributed Denial of Service), l’aggressore tenta di sovraccaricare la banda larga o le risorse del server eseguendo contemporaneamente molte richieste. Le conseguenze sono tempi elevati di caricamento del vostro sito, oppure nel peggiore dei casi addirittura l’interruzione completa del servizio. La nostra protezione DDoS è attiva permanentemente per tutti i nostri clienti webhosting da metà anno 2016. Se viene ravvisato un attacco, la protezione si aziona dinamicamente entro pochi secondi e filtra l’attacco.

PHP

HTTP/2

HTTP/2 – Siti web super veloci

HTTP/2 è l'ultima versione del protocollo di connessione internet. È stato pubblicato nel 2015. I suoi vantaggi rispetto alla precedente versione HTTP/1.1 sono i seguenti:

  • Latenze generalmente più brevi: Questo rende più veloce il caricamento dei contenuti web.
  • Un solo canale di comunicazione: In questo modo si evitano inutili sovraccarichi di dati e la trasmissione è più veloce perché non ci sono più diversi canali dati. Diversi canali dati interferiscono tra loro, rendendo la trasmissione più lenta. Con l'HTTP/2 non è quindi necessario suddividere i file di grandi dimensioni in parti più piccole per la trasmissione, per poi ricomporli nuovamente. È possibile trasferire più file in parallelo senza problemi.
  • Migliore compressione: Con HTTP/2, i dati header possono anche essere compressi, per cui è necessario trasferire meno dati. I dati header contengono importanti informazioni aggiuntive sui dati trasferiti.
  • Priorità: Il browser web può comunicare al server quali pacchetti di dati devono essere trasferiti con la massima priorità. In questo modo è possibile caricare prima i dati importanti del sito web.
  • Push dal server web: Questo permette al server web di inviare informazioni al browser web prima ancora di averle richieste. Questo rende la trasmissione più veloce perché viene eliminato il tempo per la richiesta dal browser web.

HTTP/2 è compatibile con la versione precedente, quindi non ci sono problemi con i browser web che non supportano HTTP/2.

Cronjobs

Cronjobs

Un Cronjob è un task che il computer esegue periodicamente e in modo autonomo. Si tratta di una funzione utilizzata se è necessario elaborare i dati a intervalli di tempo regolari.

Mod-rewrite (htaccess)

Mod-rewrite (htaccess)

Il modulo Rewrite consente di convogliare o riscrivere automaticamente un indirizzo Web (URL) gestito dal proprio server Web su un altro indirizzo Web. In questo modo, ad esempio, in caso di modifica della gerarchia dei file gli indirizzi Web rimangono validi. Questa funzione contribuisce anche alla maggiore fruibilità per utenti e motori di ricerca.

JavaScript & SSI

JavaScript & SSI (Server-Side-Includes)

JavaScript (in breve JS) è un linguaggio script originariamente sviluppato per l’HTML dinamico nei browser Web. Applicazioni tipiche sono i controlli dei dati, il trasferimento dei dati senza ricaricare la pagina nel browser o l’occultamento degli indirizzi e-mail per contrastare lo spam.

Gli SSI (Server Side Includes) consentono la modifica automatica di un contenuto di un sito Web su un server Web. Con questa tecnologia è possibile leggere variabili come ad esempio l’ora o la data.
