Comment fonctionne notre générateur de favicons ?

Notre générateur de favicons est très simple à utiliser : il suffit de transférer le fichier image, de le modifier, de le prévisualiser, de le télécharger et votre icône ICO est prête à l'emploi ! Ainsi, vous n'avez pas besoin de passer du temps avec un logiciel de traitement d'image, vous pouvez tout faire directement en ligne.

  1. Transférez votre image pour le favicon, si vous en avez déjà un. Vous pouvez également créer un logo selon vos préférences dans le générateur de lettres. Veuillez noter que l'image doit être carrée et faire au moins 310 x 310 pixels pour être envoyée.
  2. Le générateur de favicon convertit l'image en fichiers ICO et PNG. Votre icône a alors un format supporté par tous les navigateurs. La fonction de prévisualisation vous permet de voir à quoi ressemblera le résultat dans le navigateur et dans la version de l'application.
  3. Il ne vous reste plus qu'à télécharger ! Vous pouvez télécharger le favicon sous forme de fichier ZIP et l'intégrer à votre site Web à tout moment.

Une fois que vous avez intégré le favicon sur votre site, le petit graphique apparaît désormais à côté de l'URL dans la barre d'adresse du navigateur et, depuis peu, directement dans les résultats de recherche Google.

Obtenez votre propre favicon en 3 étapes, sans logiciel graphique : le générateur vous permet de créer un signe distinctif pour votre marque en quelques minutes.

Qu'est-ce qu'un fichier ICO ?

ICO est un fichier d'icônes Windows et, dans une certaine mesure, un paquet complet : le fichier se compose de plusieurs niveaux et contient des fichiers d'images PNG de différentes tailles sur ces niveaux. En fonction de l'endroit où la favicon est affichée, le navigateur utilise un fichier image différent du fichier ICO. Les tailles courantes de l'ICO sont 16 x 16 pixels, 32 x 32 pixels et 48 x 48 pixels. En théorie, d'autres formats de fichiers (PNG, GIF) peuvent également être utilisés comme favicons, mais uniquement dans les versions les plus récentes des navigateurs.

Le favicon parfait

À quoi doit ressembler un favicon ? En premier lieu, ne pas être trop chargé! En effet, selon le terminal et le navigateur sur lesquels le favicon s'affiche, une icône très détaillée peut ne pas s'afficher correctement. Google utilise par exemple un simple G aux couleurs caractéristiques de Google. Avec des lettres, un logo ou un emoji, vous êtes en sécurité !

Puis-je utiliser l'icône favorite pour les applications ?

Oui, c'est possible. Les icônes d'application sont les petites icônes que vous touchez lorsque vous voulez ouvrir une application sur votre smartphone (appelées icônes tactiles). Vous pouvez également les créer avec notre générateur. Cela signifie que le fichier ZIP contient, entre autres, tous les formats d'icônes nécessaires pour un affichage correct sur les appareils mobiles. Il s'agit notamment des formats 57 x 57, 72 x 72 ou 144 x 144.

Les navigateurs recherchent automatiquement les favicons et affichent un message d'erreur s'ils ne trouvent pas d'icône. Alors pourquoi s'en priver quand il est si facile de les créer - commencez tout de suite !

Pourquoi vous ne devriez pas renoncer aux favicons

Une bonne raison d'utiliser des favicons est le fait qu'ils sont très reconnaissables. Les images sont plus attrayantes que le texte, il est donc grand temps d'ajouter une icône à votre site web ! De plus, l'absence de favicon peut même avoir un effet négatif sur le classement Google. En fait, le navigateur recherche automatiquement ce graphique et envoie un message d'erreur s'il ne trouve pas d'icône. Cela augmente le temps de chargement de la page.

La favicon est prête et - et maintenant?

Vous pouvez intégrer la favicon terminée dans le répertoire principal de votre domaine avec une simple commande. Pour cela, il vous suffit d'utiliser un programme FTP tel que FileZilla et les commandes HTML suivantes. Ces commandes doivent être insérées dans le fichier HTML dans la partie <head>. 

<html>

    <head>

        <!-- Pour les appareils Apple -->

        <link rel="apple-touch-icon" sizes="180x180" href="[CHEMIN VERS L'ICON]/apple-touch-icon-180x180.png">

        <!-- Pour les navigateurs -->

        <link rel="shortcut icon" type="image/x-icon" href="[CHEMIN VERS L'ICON]/favicon-32x32.ico">

        <link rel="icon" type="image/png" sizes="96x96" href="[CHEMIN VERS L'ICON]/favicon-96x96.png">

        <!-- Pour Windows -->

        <meta name="msapplication-square310x310logo" content="[CHEMIN VERS L'ICON]/mstile-310x310.png">

        <meta name="msapplication-TileColor" content="[COULEUR HEX (ex. #000000)]">

    </head>

    <body>

        <h1>Les favicons!</h1>

    </body>

</html>

Entrez ces lignes dans l'en-tête du répertoire racine. De nombreux CMS offrent également la possibilité d'intégrer le favicon via la médiathèque dans le backend (voir ci-dessous). Notre conseil : effacez le cache du navigateur après l'intégration, sinon il se peut qu'il ne se charge pas immédiatement.

Pour les sites web, les blogs et les boutiques en ligne

Les webmasters adorent les favicons parce qu'ils constituent un ajout intéressant à tout projet web. Des petits blogs sur Blogger, Tumblr ou WordPress aux boutiques en ligne et aux grands sites d'entreprise, les favicons attirent l'attention et confèrent à la marque une grande valeur de reconnaissance.

Sur tous les navigateurs et appareils

Votre favicon s'affiche correctement dans tous les navigateurs, ainsi que sur les bureaux et les écrans d'accueil de tous les appareils, y compris les tablettes et les smartphones. Les fichiers et formats créés sont compatibles avec les spécifications individuelles de tous les navigateurs.

Formats d'image standardisés

Le générateur de favicon met à disposition des fichiers de différentes tailles de manière totalement gratuite. Vous pouvez créer l'icône correspondante en ligne et l'utiliser comme bon vous semble. Vous avez ainsi la garantie que vos icônes sont identiques sur toutes les plateformes, quel que soit l'appareil utilisé par les visiteurs du site.

Différents formats et tailles de fichiers

Vous pouvez également obtenir les icônes d'application correspondantes pour Android, iOS et Windows dans de nombreux autres formats. Vous pouvez ainsi décider vous-même comment et dans quel format vous souhaitez utiliser les fichiers générés.

FAQ : Foire aux questions
sur les favicons

Que sont les favicons ?

Une favicon est une petite icône, un symbole ou un logo de 16 x 16 ou 32 x 32 pixels utilisé par les navigateurs Web pour améliorer la reconnaissance d'un site Web. Elle apparaît notamment dans la liste des favoris, dans les onglets et, sous Windows, lorsqu'une page est enregistrée dans la barre des tâches ou créée sous forme de tuile. Les icônes ont été créées par le groupe informatique Microsoft, dont Internet Explorer 5 a affiché pour la première fois des favicons en 1999.

Comment créer une favicon ?

La manière la plus simple de créer un favicon est d'utiliser un générateur en ligne. Il vous suffit ici de télécharger l'image de votre choix, de la modifier, puis de la télécharger à nouveau aux formats ICO et PNG. Vous pouvez également utiliser le générateur pour créer une icône en forme de lettre.

Comment puis-je intégrer mon favicon dans mon site web ?

Vous pouvez intégrer une favicon à tout moment avec une commande HTML dans l'en-tête du répertoire principal :


<html>

    <head>

        <!-- Pour les appareils Apple -->

        <link rel="apple-touch-icon" sizes="180x180" href="[CHEMIN VERS L'ICON]/apple-touch-icon-180x180.png">

        <!-- Pour les navigateurs -->

        <link rel="shortcut icon" type="image/x-icon" href="[CHEMIN VERS L'ICON]/favicon-32x32.ico">

        <link rel="icon" type="image/png" sizes="96x96" href="[CHEMIN VERS L'ICON]/favicon-96x96.png">

        <!-- Pour Windows -->

        <meta name="msapplication-square310x310logo" content="[CHEMIN VERS L'ICON]/mstile-310x310.png">

        <meta name="msapplication-TileColor" content="[COULEUR HEX (ex. #000000)]">

    </head>

    <body>

        <h1>Les favicons!</h1>

    </body>

</html>
Comment fonctionne l'intégration dans un CMS (par ex. WordPress) ?

De nombreux CMS courants offrent la possibilité de modifier la favicon dans le backend. Avec WordPress (à partir de la version 4.3), par exemple, vous pouvez télécharger la favicon dans la médiathèque et la sélectionner comme nouvelle icône de site dans le menu Informations sur le site. La taille recommandée est de 512 x 512 pixels.

Dans le backend Joomla, vous pouvez rechercher votre modèle sous Extensions/Templates et il vous suffit ensuite de télécharger la nouvelle favicon via le répertoire des modèles. Si ces possibilités ne fonctionnent pas avec votre CMS, il est préférable d'intégrer l'icône comme décrit ci-dessus via le répertoire principal.

Puis-je créer le favicon uniquement avec un générateur en ligne ?

Non, il est tout aussi possible de créer des favicons avec un logiciel graphique comme GIMP ou Photoshop. Ceux qui connaissent ces programmes peuvent bien entendu procéder de la même manière. Toutefois, pour les débutants complets, l'outil en ligne est plus facile à utiliser.
